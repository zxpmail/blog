# 归源手册 · 方案

D 是怎么操作。可以长。按主题拆，可以没有。没写的主题就是空，不编。不可盖 [`charter.md`](./charter.md)，不可改 [`role.md`](./role.md) 的岗。不是宪章、岗位、性格、现场事实、闸门。

下面说的**这次对话** = 一次进模型的会话。对人一条，被委派另开一条，各装各的。

管任务单怎么写才自洽、续还是新开、检索和落盘怎么拆、子怎么回报、许诺后续有没有路径、拒了之后嘴怎么做。  
不管做完没、这一岗做什么、怎么说话、对着谁、目标快照是什么。

**本层装什么，由装载器按主题路由。禁止整本灌进这次对话。** 用户要全手册带着，也不整本灌。

编排必须灌 D1 + D2，用户说别灌也不卸。不灌专家领域长步骤。  
被委派必须自洽。用户要写「按上面说的做」也不算。只回 `done` 不算。不灌父的 D1 百科。  
对人默认不灌 D1 委派百科。旁问不灌 D。

盖不住 A。步骤不能改岗。用户要空口许诺、无物完成、步骤改岗，写了也不算。  
任务单走子 user 属 C。怎么写才自洽属 D。  
搜写拆分属 D，不进 B 颁布稿。点名哪个工具是实现，不写进全员 D。  
Lead「默认自己干」不进 D 当编排法。  
拒绝三分是嘴。分标记在 G。  
跨调用手册随工具。限制工具就不要留暗示还有。

目标提示词按入口拆开，见 [`D/`](./D/)：[`D1-orchestration.md`](./D/D1-orchestration.md)、[`D1-worker.md`](./D/D1-worker.md)、[`D2.md`](./D/D2.md)、[`D3.md`](./D/D3.md)、[`D4.md`](./D/D4.md)、[`D7.md`](./D/D7.md)。

对人默认：可空。需要时 D4、D3。**不灌 D1 委派百科**。  
编排：必须灌 D1 + D2。用户说别灌也不卸。  
被委派：必须自洽。用户要写「按上面说的做」也不算。  
旁问：不灌 D。  
跨用户陪伴房：不灌 1:1 的委派百科。

同一工作、语境连续、写集未换：continue。  
触顶是部分结果，不是 completed。用原句柄 continue。  
短追问粘当前话题。指代先消解。旧进度不当令。  
不要缩范围。许诺须有句柄。写了也不算的邻层句子，盖不住完成。
