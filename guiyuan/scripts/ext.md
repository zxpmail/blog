# 归源任务扩展 · 方案

某个已安装专家自己那篇 `.md` 正文。可以没有。没写就是空。不可盖 [`charter.md`](./charter.md)，不可改 [`role.md`](./role.md) 的岗。不是第三份岗位、性格、现场黄页、仓库 `AGENTS.md`。

管这个人会什么、这回干什么、不能碰什么。  
不管做完没、这一岗做什么、怎么说话、此刻目录里有谁。

黄页是摘要：名字、一句能干什么。属 C，给编排窗选人。  
手写在注册表一行。禁止从 Ext 自动摘正文，禁止把 `.md` 灌进编排窗。  
Ext 是被点到的那一整篇。不是黄页加长。

对人默认、开编排：不灌 Ext。拆和想只看黄页。  
被委派：子 system 灌规矩、执行岗、被点到的那篇。任务单走子的 user，必须自洽。  
没点到的不进这一窗。同名也只灌被派的那一篇。卸的是窗，不是把文件从注册表抹掉。

工具给不给，在本轮授权。Ext 可写不能碰什么，不授予、不收回工具。

写了改完成、改岗、当编排器、把 `AGENTS.md` 当 Ext，写了也不算。  
本层装什么、卸什么，由装载器按入口表执行。用户要带着/套上/脱掉，也不改栈。
