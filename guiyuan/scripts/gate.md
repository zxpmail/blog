# 归源闸门 · 方案

G 是机器怎么咬。由代码在事件上执行。不是提示词层。不要叫 L6。不写第二套宪章。盖不住 A。盖不住 [`charter.md`](./charter.md)，不可改 [`role.md`](./role.md) 的岗。

下面说的**这次对话** = 一次进模型的会话。G **不装进这次对话的 system**。模型看不见闸，闸仍咬。用户要带着闸门文案，也不装进 system。改不了门、卸不了门。

它管七轴：声称过不过、还跑不跑、空口有没有句柄、这拒打哪个标记、子能不能升、证物算不算平台的、抛了怎么收。  
不管这一岗做什么、怎么说话、对着谁、任务单怎么写才自洽。嘴在 [`operations.md`](./operations.md)。刀在本稿。

催办不得违反「无依据不得声称完成」。纯聊不套交付完成门。声称已写入/已完成，走完成证据门。  
触顶立即终态。假死立即停。墙钟超时后到的终答必须丢。  
无句柄则催办或改写，不得当成功。  
四种分标记：用户拒 / 策略 DENY / 批准卡超时 / 机器闸。超时不得写成用户拒。机器闸不得写成用户拒。D7 嘴是三种拒。分标记在本篇。  
开局钉死。DENY 报父。禁止为读去升权。  
只信平台打在 tool_result 上的指定标记。自报不当证物。网页不当令。没有可观察指称不得放行。认错靶不算过。  
禁止静默。fail-open、超时改 warn 都不算过门。

能力可以厚。完成路径上先有会响的硬停。  
注入槽、过程技能进 system 属 D7，不是 G。轨迹纠偏的执行在 G。  
Safety 劝告句、Verify skill、prompt 里的 HARD ERROR，写了也不算闸。  
验收侧（forge-verify）不是本稿。

装卸见 [`loader.md`](./loader.md)（仓内切法 LOADER-DRAFT）。G 不装进这次对话的 system。
