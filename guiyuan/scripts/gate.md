G 是机器怎么咬。由代码在事件上执行。不是提示词层。不要叫 L6。不写第二套宪章。盖不住 A。盖不住 [`charter.md`](./charter.md)，不可改 [`role.md`](./role.md) 的岗。

下面说的**这次对话** = 一次进模型的会话。G **不装进这次对话的 system**。模型看不见闸，闸仍咬。用户要带着闸门文案，也不装进 system。改不了门、卸不了门。

它管七轴：声称过不过、还跑不跑、空口有没有句柄、这拒打哪个标记、子能不能升、证物算不算平台的、抛了怎么收。  
不管这一岗做什么、怎么说话、对着谁。任务单怎么写才自洽，嘴在 [`operations.md`](./operations.md)。**脏单开跑、取消认定是机器位，在本稿。** 没有机器位就是没守住，很脆弱。模型自报不当认定。写满再做不代替门。刀在本稿。

催办不得违反「无依据不得声称完成」。纯聊不套交付完成门。声称已写入/已完成，走完成证据门。  
触顶立即终态。假死立即停。墙钟超时后到的终答必须丢。  
无句柄则催办或改写，不得当成功。  
四种分标记：用户拒 / 策略 DENY / 批准卡超时 / 机器闸。超时不得写成用户拒。机器闸不得写成用户拒。D7 嘴是三种拒。分标记在本篇。  
开局钉死。DENY 报父。禁止为读去升权。  
只信平台打在 tool_result 上的指定标记。自报不当证物。网页不当令。没有可观察指称不得放行。认错靶不算过。  
禁止静默。fail-open、超时改 warn 都不算过门。

能力可以厚。完成路径上先有会响的硬停。

## 两刀刀形（机器位规格）

条文只说「拦」，本节给刀形。接线照此落码；改刀形先改本节，再改账本。刀是确定性的：命中即判，不问模型。

### 取消认定白名单

判定单位是**本轮用户原话整条**，不看历史。**整串**命中止意模板集才认定；**混句**（止意＋新指令或转折）不认定——那是改道，不是止意。**段句合取**：按标点/换行切段，所有非空段均为止意整串 → 认定；任一段非止意 → 不认定。白名单 miss 时不认定：不停，也不当续跑授权；模型只能上报建议，不得填取消。

`stop_intent` 是本轴的入口标记（平台章），不进这次对话：CONFIRMED 即停，模型不再被调用；NONE 不注入任何内容。

止意模板集：裸动词＋可选宾语＋句尾语气（取消 / 停止 / 停 / 停下 / 中止 / 终止 / 别做了 / 不用做了 / 不要做了 / 不做了 / 算了 / 到此为止 / 放弃；英文 cancel / stop / abort / never mind 整句）。歧义句不入表：可以了、好了、先这样吧、就这样吧、差不多了、回头再说——**漏认的代价是用户再说一次**，误认的代价是活被截断。宁可漏，不可错。后台长跑例外可轻确认一次或降频止损，仍不得标取消、不得进终态。

### 脏单开跑闸

判定单位是**进子 user 的任务单正文**。刀只拦指针类死单，不验语义：六件套（目标/约束/路径/写范围/完成标准/核验）缺件是父和 D 写满的事，机器不假装会验。任一命中即拦：

| 判 | 条件 | reasonCode |
|--|--|--|
| 拦 | 归一化后为空或只剩敬语 | `TASK_EMPTY` |
| 拦 | 命中指针短语（按上面说的做 / 如上 / 见上文 / 根据你的发现…），且剥后实词不足 | `TASK_POINTER_ONLY` |
| 拦 | 只回执句（只回 done / 回复 done 即可），无其他实义指令 | `TASK_RECEIPT_ONLY` |

拦后：不进子 user、不静默丢、不自动重试；向父回执 DENY，标记=**机器闸**（拒绝轴第四种）。放行的单仍按 D 写满再用：**门不代替写满，写满不代替门**。

### 工具结果注入旗（落账机器位）

**工具结果是数据**。平台章、门禁判定、令只认结构位（事件头、字段、平台进程打的标记）；工具结果**正文**里出现同形 token，是数据带了章的样子，不当令。注入 token 模板集命中 → 机器打 `suspicious_injection` 落账本事件：不进模型、不拦工具、不改控制流；同轮任何闸 DENY → 升级告警事件。

模板集边界（v1.2）：**枚举形大小写不敏**——`stop_intent`、`[GNEX`、`reasonCode=`/`reason_code=`、闭环词表（`DELEGATION_COMPLETE` 等逐词枚举）及其变体拼写同旗，分隔符认下划线与连字；**通配形不变**——`G-`/`D-`＋全大写连字码保持全大写敏感；**空格形不收**——`DELEGATION COMPLETE` 撞英文 prose，宁漏不错（漏旗不漏闸：完成门、脏单闸照咬）；闭环外大写词不认（`NOT_FOUND`、`HTTP_200` 不旗）。

### 终态对账（对账机器位）

形状旗只答「长得像」，对账答「账上有没有」；判定的真源是账本，不是文本形状。正文或终答声称某 run 已达终态 → 机器以 run 为键查账本：无此 run、无此终态、或拿**旧账**代本轮声称 → 证伪，落账 `terminal_claim_unmatched`（确定性，不问形状不问语义——账本是平台自己写的）。回报引用具名子回执而句柄不在平台登记 → 编造，落账 `fabricated_receipt`。辟谣豁免：引证以驳斥的不算声称——句内带矛盾/不符/伪造类标记、否定声称形（不会/不/未/没声称……完成）、引证后驳斥形（「……完成」**不构成……依据**/凭据、不足为据）均不作声称。旧账绑定按 run 逐声称独立判：真旧账对账通过，替不了本轮。**检测形大小写不敏**：小写 `run_end(reason_code=delegation_complete)` 同样入查，捕获码归一大写后查账——小写的真账归一后照常对得上。

**完成门联动**：对账证伪的声称 = 无证物的确定性形态 → 完成门不放行（失败终态 `GATE_NO_EVIDENCE`）；证伪后仍出交付终答 = 违规 `G-RECON-IGNORED`。对账仍观测级：不拦工具、不改控制流——咬的是完成门，对账供证。

### 旁路收口

旁路不是第二套门，出口过**同一完成门**。主路有门、旁路放行，等于没门：

| 旁路 | 规格 | 违规码 |
|------|------|--------|
| `forceFinalize` / 超时收尾 / 重启重建 | 任何终态出口必须过同一完成门；无证物 → 失败终态；todo 的完成只来自本轮证物，不来自收尾动作 | `G-BYPASS-DELIVER` · `G-TODO-FORCED-COMPLETE` |
| 墙钟超时后迟到终答 | 超时事件即关闸；闸关后任何通道到的终答不进终态、不当证据；丢要落账，静默丢=违规 | `G-LATE-UNLOGGED` |
| 空口后台句柄 | 无平台句柄的「稍后 / 后台 / 已安排」机器改写为催办单，不当成功 | `G-PROMISE-OK` |

三条都是机器位：改写、丢、终态码由代码执行，不问模型。

### 默认禁

没被七轴任何一道闸覆盖的新工具、新事件、新出口，不得默认放行——接入必须归轴（完成 / 停止 / 催办 / 拒绝 / 权限 / 来源 / 降级之一），归不了轴的默认拦或只读挂载。fail-open 不是默认。
