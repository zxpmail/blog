# Harness 的边界

**或者：绿勾通过的那一刻，拦网可能刚被你剪断**

*2026-07-13*

> 接[《镜子》](blog-essay-mirror-no-thought.zh.md)停在 `rules.py` 前面的那只手：这篇写手还是伸了——剪掉的若是牙，绿得越早，空得越晚。

---

我删过那样的二百行。

状态机、校验、一条在模型撒谎时仍会咬住的拦截。旧规则很笨：状态不是 `confirmed`，就不许写出 `done`——不管模型话多圆。最后几行每次收尾都要跑——钝，显老，演示前夜挡手。我把它们标黄，准备剪。换成 system prompt 里三句：「输出前确认状态合法」。模型配合得很好。

点删除之前，手停过一下。说不出为什么。光标在那块黄上闪。闪完，我还是点了。那几行没了。屏幕绿了。有人在频道里说：这就对了，Harness 该瘦。我回了个表情。松了一口气——松错了。

后来才敢问自己：被我剪掉的，是提醒，还是牙。

提醒可以搬家到 prompt。牙不行。牙是环境：不论模型想不想，都咬得住。prompt 里的「请自查」是请求。模型和验收共用文本通道时，「查过了」和「声称查过了」长得一样。强制一滑成自觉，兜底就退回自报告。

上一面追分、盖过滤，和这里删牙，是同一只手：用好看的通过，换掉不肯好看的硬东西。差别只是文件名。那边叫 `rules.py`。这边叫拦截。壳会搬家。形式迁，牙不能迁成礼貌。省提醒，省出速度。省牙，省出事故——这话当时还只是怕。

剪完那天，演示没有报错。我把笔记本合上，像办完事。

然后等。不是等顿悟。是等一句足够像真的谎。

第一周，什么也没有。我几乎相信剪对了。第二周，夜里还会打开那份 diff，看黄块消失的位置，又关掉。第三周，它来了。没有多轮商量。一轮输出里，状态机还停在 `awaiting_confirm`，正文已经写成 `done`。三句自查都在日志里，排得整齐：第一句查了「有没有输出格式」——有；第二句查了「字段齐不齐」——齐；第三句写「状态合法」——它把「能说出 done」当成了合法。查过了。查的是别的。旧拦截若还在，会在写 `done` 之前直接拒——不问它自查过没有。我去翻那个位置——空的。黄块早剪掉了。

频道里只剩 deploy 记录和 ping。没有人回头翻那几行 diff。我也不知道该不该翻。只有光标，停在那三句 prompt 边上，一下一下闪。我对着闪了很久。久到咖啡凉透。没有人来问为什么演示周那么顺——顺，好像本来就不需要解释。

坐在那条缝前面，才看清半句真正危险的话：模型强了，强制可以省。礼貌就是从这儿漏出去的。

我没有立刻把二百行贴回去。手在。文件在。过了一会儿，才开始敲。敲的时候没有人鼓掌。屏幕也没有因为牙回来多亮一点。

绿还在昨天的录屏里。颜色还在。它证明过演示。没证明过牙还在。
