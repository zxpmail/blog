# Harness 的边界

**或者：绿勾通过的那一刻，拦网可能刚被你剪断**

*2026-07-13*

> **弧线 · 清醒（工程）。** 从深渊里先醒一层：轻不是进步；强制不是自觉。前一篇深渊：[镜子](blog-essay-mirror-no-thought.zh.md)。下一刀清醒在论证：[六处审稿](blog-essay-six-defense-lines.zh.md)。

---

我删过那样的二百行。

状态机、校验、一条在模型撒谎时仍会咬住的拦截。最后几行每次收尾都要跑一遍状态校验——钝，显老。演示前夜，我嫌它挡手。换成 system prompt 里三句：「输出前确认状态合法」。模型配合得很好。一次通过。有人说：这就对了，Harness 该瘦。

点删除之前，手停过一下。说不出为什么。然后还是点了。光标还在原位。那几行已经没了。屏幕绿了。我松了一口气——松错了。

后来才敢问自己：被我剪掉的，是提醒，还是牙。

提醒可以搬家到 prompt。牙不行。牙是环境：不论模型想不想，都咬得住。prompt 里的「请自查」是请求。模型和验收若共用文本通道，「查过了」和「声称查过了」长得一样。强制一滑成自觉，兜底就退回自报告——绿勾贴在脑门上的那种。深渊里追分、追干净，和这里删牙，是同一姿势：用好看的通过，换掉不肯好看的硬东西。

有人争 Harness 会不会消失。争错了地方。不该问「要不要壳」，该问「这一层还能不能在模型说谎时按住它」。壳会搬家。形式迁，牙不能迁成礼貌。

真正危险的句子是：模型强了，强制可以省。

省提醒，省出速度。省牙，省出事故。设计师的问题不该是「三句能否代替二百行」，而是「二百行里有几行从来不是给人看的——是给世界挡一下的」。

剪完那天，演示没有报错。

然后我等了几周。有一句谎说得足够像真——礼貌地通过了。我去找牙。牙不在了。只剩三句请自查，还在点头。

清醒的第一层就这一句：绿不是证明。绿只是颜色。颜色还在。我还坐在它前面。
