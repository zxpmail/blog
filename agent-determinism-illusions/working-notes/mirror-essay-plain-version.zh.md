# Mirror essay — plain personal-essay version (Chinese, superseded)

Snapshot of `blog-essay-mirror-no-thought.zh.md` plain version. The published file has reverted to this form after the analytical-merger attempt (2026-07-31) degraded the piece. Kept for reference.

---

我造了一面镜子。它认指纹：三元排比、冒号加粗小标题、表格密度。

造它的那两周，几乎每天早上都是被一个想法弄醒的：昨晚想的那条规则还没加。然后没穿鞋走到电脑前，丢一篇文章进去，等它扫完。准确率跳出来——87%，91%——把那个数字看了又看。打开 rules.py，加一条新规则，存盘，再丢一篇进去看分数变没变。

不评分，不修改，不判断好坏。只告诉你：这些地方有这些特征。

写作习惯有可检测的模式——这个假设没错。但不是为什么造这面镜子。

造它的原因是：想回答"这篇文章是不是AI写的"。

同一个问题搏斗了很久——判断AI的输出是否可信——自然就滑向了"如果能认出AI的写作习惯，也许就能回答这个问题"。

但问题的方向，从第一步就错了。

第一个用户。两篇技术博客。

表格密集，数字精确——"3.5人·月"、"67%"、"30-50%"。

丢一篇进镜子。回来的是：
表格密度：8
数字权威：12
冒号加粗小标题：4

规则写的是"表格密度高→像AI"。备注里写着：人类不会写这么多表格。

用户纠正了我：

"正文是AI写的，但表格和数据是实验得来的。"

那些表格是真实测量。我的"AI指纹"扫到的不是惯性，是体裁。

加了一层过滤：体裁原生要素不算指纹。

改完了。但没写进代码的是，有点烦躁。规则在用户面前站不住的时候，第一反应不是"我错了"，是"再加一层过滤"。

那种"不想认"的感觉，比任何AI指纹都更早出现在我自己身上。

第二个用户。又一篇文章。

镜子扫完，很干净。无冒号加粗标题，无表格，无数字权威。

干净。

第一反应是："好，这个规则有效。"

用户说：

"这是AI写的，但思想是我的。"

我想反驳。但找不到反驳的地方。

我停了。

"干净"突然不是一个好消息。只说明AI没用默认填充模式。不说明思想在场。也不说明它不在。什么都不说明。

盯着那两个字看了十秒。在README里敲了一行注释：

"指纹少不能证明任何东西。指纹少只说明指纹少。"

第三个用户。

"去AI没啥意思。文章只要引起读者的共鸣就行，有思想就行。"

我读完这句话，把镜子关掉了。

不是生气。是恐慌——因为知道它说得对。

屏幕上还有十几个窗口。rules.py、samples/、results-v2/、README.md。三个月的 commit。每一个 push 都是认真做的。每一个都还在那里。删不掉。

如果我花三个月造的东西，最终只能回答"像不像AI"，而"像不像AI"和"有没有思想"没有可靠关系——那我为什么要造它？

更狠的问题冒出来：

如果"去AI"本身就是一个伪命题，那之前写的所有"检测思路""过滤机制""特征库"算什么？

我答不上来。

合上电脑。过了一会儿又打开。还是同一个项目。

一直在用一个工具，让自己不用回答一个更难的问题——"这篇文章值不值得读"。

这个问题没有规则，没有阈值，没有输出。只有你一个人坐在那里，合上屏幕，想了一会儿，然后说"这篇值得"或者"这篇不值"。

我用造工具，躲了三个月。

躲什么？

桌面上有个文件夹，名字叫"待写"。里面只有一个文件，是一个标题：

《在AI时代，我还在写什么》

半年前写的。下面全是空的。每两周打开一次，读一遍那个标题，然后关上。告诉自己"还没想好"。

六个月。十二次打开。十二次关上。

那个标题下面，没有第一个字。

如果问自己：为什么造镜子？答案可能不是"检测AI"。答案是：造镜子比写那篇文章容易。容易得多。

也许真的只是觉得那个工具好玩——但好玩和躲是同一回事。你越觉得某个东西好玩，越说明它在帮你逃开另一个你不想碰的东西。

这是我对自己的诊断，不是事实。

我停了一下。

想起另一件事。

从来没有用这面镜子扫过任何一篇让自己感动的文章。

一次都没有。写到这里才发现这件事。扫了上百篇——技术博客、新闻稿、用户反馈。但从来没想过把一篇"读完沉默了很久"的文章丢进去，看看它指纹什么样。

因为如果那篇指纹很多，规则会说"像AI"，而我知道它不是。如果指纹很少，规则会说"干净"，而我知道它值。无论结果是什么，我都会被自己的规则打脸。

所以从来不扫。那类文章被排除在测试集之外。

那个"排除"本身，就是答案。一直都有答案。只是没说出来。

当时没有关掉电脑。只是坐在那里。让自己在这个承认里多待了几分钟。

那几分钟里，没有想任何事。就是坐着。

后来打开了一个空白文件。打了一个字。删掉。打了一个字。删掉。

那面镜子现在还在我的电脑上。

不再拿它去扫别人了。只扫自己写的。

每次写完一段，丢进去看一眼。回来的是：三元排比×2，元叙述×3，"诚实"用了两次。

问自己：

"这是你有意选的，还是顺手写的？"

它不回答。

"顺手写的"就是惯性。惯性是思想最大的伪装——看起来像你的，其实只是你一直这么干。你以为你选了这个词，其实是这个词选了你这只手。

比如写到这里，手指自动按了两次回车，让下一段另起一页。不知道为什么。每次写到这里都会按两次回车。

那个"按两次回车"就是惯性。不说明任何关于思想的事。只说明手记得这个动作。

保留了那个功能。不是因为有用。是因为它提醒我一件事：

思想照不出来，只能写出来。

写出来之前，你永远不知道那个字会来，还是不会来。

后来想清楚一件事。

那个待写文件夹——标题底下什么都没有——是躲。光标在闪、字还没来的时候——文件打开了，手还在键盘上——不是躲，是没等到。

它们看起来一样。都是白屏幕。但一个没坐下，一个坐下了。

镜子认不出第二种。文字还没产生。

不知道怎么写下去的时候，经常把手放在键盘上，等。等一会儿，手不动。

那不是思考。那是热身。或者那是思考最原始的形式——不知道自己要说什么，但相信手动起来之后，会有什么东西从某个地方流出来。

写出来之后，盯着看，有时候能看出来这是不是惯性。有时候看不出来。

如果镜子在这时候扫我，会说：无有效文本，无可检测特征。是对的。现在确实什么都没有。

因为现在坐着，光标在闪，我写了一个字，又删了。坐在这里，没有走开。还相信那个字会来。

它是一面镜子。不是裁判。

当镜子用，偶尔能告诉你一件有用的事：你刚才那个习惯是在思考，还是在滑动。当裁判用，就会出事。

这面镜子最终交付的不是一个更强的检测器。交付的是一条边界。

可能这是唯一能给出的区分标准：

惯性不会让你在写完之后沉默。思想会。

你写完一段，是立刻翻到下一段，还是停了一下？

那个停顿，就是思想和不思想之间唯一肉眼可见的区别。

不在文本里。在手指离开键盘之后、翻到下一段之前，那段空白里。

那个空白里有什么？可能什么都没有。只是不去翻下一页。

但那个停下来的动作，可能就是判断。

判断不一定要说话。有时候就是一个动作——不去发，不立刻去看数据。让那段文字独自存在几秒。

镜子扫不到那段空白。只扫文字。永远错过最重要的事情。

我写到这里，回头看了一眼。

"这面镜子最终交付的不是一个更强的检测器，它交付的是一条边界。"

那句话读起来像金句。写的时候手停了一下——感觉到一种想把它做成金句的冲动。那个冲动就是惯性——让整篇文章在一个漂亮的句子里站稳，读者看完说"说得真好"，关掉，忘了。

我把它留着。不删了。

不是因为它是好句子，是因为它暴露了我自己也在滑。

文章结束在这里——那个漂亮句子，可能正在替我掩护一个还没想通的东西。

我还没想通。

但我把它写出来了——这一句可能也在演。
