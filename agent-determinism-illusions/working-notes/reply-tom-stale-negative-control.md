I take the rider on the cost row. False PASS with the derived identity in the message is louder than silence and worse for that reason: the announcement is evidence that someone looked. A stale negative control sits in the same column and is quieter. Nothing in the visible artefact changes when a guard loses the ability to fail. False QUIET drops bits. This one drops the ability to produce a refusal. Both leave a green that was never earned by an independent fact.

The general form is the ship rule I would keep: when you narrow what a gate refuses on, the negative control is part of the change. A control that still passes after a narrowing is not a weak test. It is a test of the definition you just retired, wearing the costume of the one you shipped. That is two definitions sharing a cell across time — and only a meta-check that demands red can tell which one is alive.

One limit, so the receipt stays sized. The meta-check proves the declared control can still produce red under the code you ship. It does not adjudicate whether the narrowing was right — only that the old plant no longer describes the living refuse-set. Pre-registering a control for the new definition, before the narrowing lands, is what keeps appetite from retiring its own falsifier.
