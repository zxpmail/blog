四通道交互DAF ⇄ GNEX3 · 唯一边界 = daf-agent-bridge

四项硬约束的交互面落地：开放协议（A2A/MCP/CloudEvents/OIDC）+ 契约由 DAF 倒推定义并版本冻结（N/N-1 双活）+ Adapter SPI 防腐（GNEX3 升级影响半径 ≤ bridge）+ mock 先行开发。全库解耦冻结门：GNEX3 专有标识检索命中 = 0。
① 任务通道
业务流程委派 agent 任务（含回调/中断恢复/超时策略）；委派深度=1
A2A 最小子集 · taskId 幂等 · deadline+onTimeout
② 工具通道
agent 以 MCP 工具消费/组装 DAF 能力；15 工具族从语义卡能力 IR 编译；per-agent 裁剪
MCP streamable HTTP · OAuth2.1 RS · 幂等键必填 · untrusted framing
③ 事件通道
业务事件触发 agent；agent 事件回流业务；载荷最小化（ID+摘要）+ 订阅 ACL
CloudEvents 1.0 + HMAC-SHA256 防重放 · 死信重放
④ 身份通道
用户/agent 身份联邦；agent=技术委托主体（最小权限+act 链强制+定期复核）
OIDC + RFC 8693 token exchange · sub 统一标识

机制设计

语义卡（daf.card.v1 · 四段式 · 唯一事实源 P5）

metadata 元数据段
id / semver / title / tags / owner / deprecated / sourceModule——制品身份与归属
semantics 语义段（给 LLM）
summary ≤200 字 / whenToUse / whenNotToUse / examples ≥1——模型选型靠语义文本
spec 结构段（给机器）
JSON Schema 2020-12 strict 子集 + 字段级业务含义 + IO schema——可校验可生成
governance 治理段（给护栏）
riskLevel / sideEffects / idempotent / requiresApproval / requiredScopes / compliance / previewable
